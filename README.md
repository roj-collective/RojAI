# RojAI

> AWS-powered AI commerce assistant built for the AWS Builder Program.

RojAI helps sellers generate high-quality product listings using generative AI and a serverless AWS architecture.

## Features

- 🤖 AI-generated product titles
- 📝 Product descriptions
- 📌 Bullet points
- 🔍 SEO optimization
- 🏷️ Product tags
- ☁️ AWS-native serverless architecture

## Tech Stack

- React + TypeScript + Vite
- Python 3.12
- AWS Lambda
- Amazon API Gateway
- Amazon Bedrock
- Amazon S3
- Amazon CloudWatch
- AWS CDK
